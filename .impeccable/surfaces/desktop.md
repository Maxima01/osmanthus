# Desktop evidence workspace

Mode: Operate. Code-led native Slint application. Windows desktop only.

The user authorized a preliminary build based on the earlier Rust architecture
discussion and explicitly deferred complex work. Product scope and framework
come from that discussion. Styling is a provisional implementation choice, not
a separately approved brand direction or image comp.

## THESIS
Make the evidence for an application's behavior readable before offering verdicts.

## OWN-WORLD
Evergreen and sage provide a quiet evidence-reading field; amber always identifies
provenance or uncertainty. Standard Slint Fluent controls provide the Windows
affordances. Segoe UI is the native application type voice, not a display motif.

## STORY
Load an explicitly synthetic sample or import a recording; inspect process
lineage; follow a review signal to an exact source event; inspect a file without
execution; reopen local history; see what remains deferred.

## FIRST VIEWPORT
A small product header, three concrete actions, persistent evidence provenance,
and a tabbed work area. The initial state states that no recording is loaded.
Behavior places the tree next to a copyable detail pane; the source IDs stay
attached to the activity. No health/protection score is invented.
